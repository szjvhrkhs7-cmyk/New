# Путевой дневник

Текущая зафиксированная версия приложения «Путевой дневник» для D&D.

Это рабочая промежуточная итерация: визуальная оболочка книги, адаптивная мобильная версия, вкладки «Хроники», «Персонажи», «Атлас» и демонстрационные записи.

## Проверка

```bash
cd chronicles-explorer
python3 -m http.server 4173
```

Открыть `http://localhost:4173`.
