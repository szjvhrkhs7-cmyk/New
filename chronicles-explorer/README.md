# Путевой дневник

Зафиксированная промежуточная версия D&D-приложения в формате записной книги путешественника.

В этой контрольной точке реализованы:
- визуальная оболочка раскрытой книги для desktop;
- компактная одностраничная версия для телефона;
- вкладки «Хроники», «Персонажи», «Атлас»;
- выбор игровых дней, персонажей и записей атласа;
- тёмная плавающая панель редактирования в стиле мобильного референса;
- демонстрационные данные и встроенный облегчённый графический спрайт.

## Локальный запуск

```bash
cd chronicles-explorer
python3 -m http.server 4173
```

Открыть `http://localhost:4173`.

## Проверка JavaScript

```bash
node --check src/app.js
```
